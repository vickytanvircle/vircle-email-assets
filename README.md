# Vircle email assets

Images for Vircle email newsletters, served with GitHub Pages at
`https://vickytanvircle.github.io/vircle-email-assets/<campaign>/<variant>/<file>`.

## Rules

- One folder per campaign, named `YYYY-MM-topic`.
- Each campaign keeps its own copy of every image (logo, icons, mascot), so changing one campaign never changes another.
- **Once a campaign is sent, never rename, move or delete its files.** Emails already in inboxes load them from here.
- Only finished, public email images. No customer data, drafts or internal files. Deleted files stay in Git history.
